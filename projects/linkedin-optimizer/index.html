LinkedIn Profile Optimizer

An automated n8n workflow scrapes a LinkedIn profile with Playwright, uses AI to analyze each section, and rewrites the headline, about, experience, and skills. It then produces a before and after report with SEO keyword impact analysis.

Tech stack

n8nOpenAIPlaywrightGoogle DriveAutomation

Key features

  • AI analysis of the headline, about, experience, and skills sections
  • Before and after comparison report with SEO keyword impact
  • Automated delivery to Google Drive for client handoff
  • End-to-end no-code automation with error handling
