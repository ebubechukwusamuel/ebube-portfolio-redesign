Twitter/X Automation

Automated Twitter posting for @ebubechukwu_sam using browser-based automation via Playwright (no API keys needed). It logs into x.com in an existing Chrome session, reads posts from markdown files, and publishes them.

Key features

  • Post management via markdown files in posts/ directory
  • AI-generated content using Groq SDK for varied posting
  • Content strategy: services, building in public, design/dev insights
  • Runs in existing Chrome session via PlayWriter extension
